# 🔥 Churrasco VIP — Landing Page

Landing page moderna e responsiva desenvolvida para divulgar um evento de churrasco, com identidade visual temática, animações e funcionalidades interativas.

## 🚀 Funcionalidades

- **Design responsivo:** adaptação para desktops, tablets e dispositivos móveis.
- **Hero section animada:** ilustração de churrasqueira com efeitos de fumaça e chamas.
- **Seletor de ponto da carne:** interação para escolher entre mal passada, ao ponto e bem passada.
- **Navegação por seções:** acesso rápido às informações do evento.
- **Integração com Google Maps:** acesso à localização do evento.
- **Confirmação via WhatsApp:** formulário que prepara uma mensagem com nome e quantidade de participantes.
- **Acessibilidade:** suporte à navegação por teclado e preferência por movimento reduzido.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- WhatsApp Link API
- Google Maps

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para executar a versão local.

## 🎯 Objetivo

Aplicar conceitos de desenvolvimento front-end na construção de uma página visualmente atrativa, interativa e responsiva, integrando recursos externos para facilitar a comunicação e a localização do evento.
