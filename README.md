# 🔥 Churrasco VIP — Landing Page

Landing page responsiva desenvolvida para divulgar um evento de churrasco, com foco em **design moderno, experiência do usuário, interatividade e integração com serviços externos**.

O projeto utiliza HTML, CSS e JavaScript para criar uma página visualmente atrativa, com elementos dinâmicos e funcionalidades que facilitam a confirmação de presença e o acesso à localização do evento.

## 🚀 Funcionalidades

- **Design responsivo:** adaptação a diferentes tamanhos de tela.
- **Interface temática:** identidade visual inspirada em churrasco, com cores escuras, animações e efeitos visuais.
- **Interatividade:** seletor de ponto da carne com atualização dinâmica da interface.
- **Confirmação de presença:** formulário integrado ao WhatsApp.
- **Localização do evento:** acesso direto ao Google Maps.
- **Organização do código:** separação entre estrutura HTML, estilos CSS e funcionalidades JavaScript.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura e semântica da página.
- CSS3 — estilização, responsividade, animações e efeitos visuais.
- JavaScript — interatividade e manipulação de elementos da interface.
- Google Fonts — tipografia.
- WhatsApp — integração para confirmação de presença.
- Google Maps — acesso à localização do evento.

## ▶️ Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar a versão estática da aplicação.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar e demonstrar conhecimentos em desenvolvimento web front-end, organização de código, construção de interfaces responsivas e implementação de interações com JavaScript.

- Adicionar testes automatizados.
