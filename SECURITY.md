# Política de Segurança

## Escopo
O Churrasco VIP é uma landing page estática. Na versão atual, não possui backend próprio, autenticação ou banco de dados. O formulário prepara uma mensagem e direciona o visitante ao WhatsApp.

## Comunicação de vulnerabilidades
Se identificar um possível problema de segurança, entre em contato com o mantenedor por um canal privado. Evite publicar dados pessoais, credenciais ou detalhes que possam colocar usuários em risco em issues públicas.

## Dados e privacidade
O site não armazena os dados preenchidos no formulário. O nome e a quantidade de pessoas são incluídos na mensagem preparada para o WhatsApp, e o visitante decide se deseja enviá-la.

## Boas práticas
- Não coloque senhas, tokens, chaves privadas ou dados pessoais desnecessários neste repositório.
- Mantenha links externos e dependências sob revisão.
- Reavalie esta política se o projeto passar a utilizar APIs, backend ou armazenamento de dados.
